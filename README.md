# 見切り侍 (Mikiri Zamurai)

一対一で相対した敵武将の斬撃を、ぎりぎりのタイミングで「見切り(パリィ)」する。
それだけに焦点を絞った、2Dサムライ対決アクションゲームです。

- 言語 / エンジン: C++ / DxLib
- 開発環境: Visual Studio 2022
- 対応OS: Windows

## 概要

プレイヤーは画面左側の武士を操作し、画面右側に立つ敵武将と正面から向き合います。
敵は「待機 → 予備動作 → 攻撃 → 硬直」のサイクルで刀を振ってくるので、
攻撃が来るタイミングを見極めてSPACEキーを押し、パリィを狙います。

操作できるのはSPACEキーひとつだけですが、パリィが成立する時間はごくわずかです。
早すぎても遅すぎても失敗になるため、敵の予備動作をよく見て「見切る」ことが
このゲームの核となる遊びです。

## 遊び方

1. 敵が刀を構える(予備動作)と、画面に「!」の警告が表示されます。
2. 警告が出てから実際に斬りかかる瞬間の前後、ごく短い間だけパリィが成立します。
   このタイミングでSPACEキーを押すとパリィ成功です。
3. パリィに成功すると、プレイヤーが敵の刀を受け止めるプロテクトのポーズを取ります
   (敵が刀を振り終えるまでそのまま構え続けます)。
4. 失敗すると、プレイヤーが被弾のリアクションを取ります。
5. パリィに5回成功するとクリア、3回失敗するとゲームオーバーです。
6. クリア/ゲームオーバー画面でSPACEキーを押すとタイトル画面に戻ります。

## 操作方法

| キー / 操作          | 動作                                   |
| --------------------- | -------------------------------------- |
| SPACE                 | パリィ / リザルト画面からタイトルへ戻る |
| マウスクリック(タイトル画面) | 「プレイ」ボタンでゲーム開始     |
| ESC                   | ゲーム終了                             |

## 特徴

- SPACEキー1つに集約した、シンプルながら判定がシビアなパリィアクション
- 待機/予備動作/攻撃/硬直の4状態を持つ敵のステートマシンと、それに連動したアニメーション
- パリィが実際に成功したときだけプロテクトポーズを表示し、敵の攻撃モーションに
  合わせてその場で構え続ける、モーション同期の作り込み
- タイトル・バトル・クリアのそれぞれに専用の背景を用意し、画面ごとに雰囲気を演出
- 処理落ちしにくい環境でも一定のテンポで遊べるよう、上限フレームレート(30FPS)を設定
- コメント・画面表示ともに全編日本語で統一

## 動作環境 / ビルド方法

1. [DxLib](http://dxlib.o.oo7.jp/) をダウンロードし、プロジェクトの
   「追加のインクルードディレクトリ」「追加のライブラリディレクトリ」に
   DxLibのパスを設定してください。
2. Visual Studio 2022でソリューションを開き、ビルドします。
3. 実行ファイルと同じ階層に `data` フォルダ(画像アセット一式)が
   配置されている状態で実行してください。

## プロジェクト構成

```
parrygame/
├─ Sourse/                 # ソースコード一式
│  ├─ main.cpp              # エントリーポイント、メインループ、フレームレート制御
│  ├─ Scene.h / .cpp        # シーンの基底クラス
│  ├─ SceneManager.h / .cpp # シーン切り替えの管理
│  ├─ ISceneChanger.h / .cpp# シーン切り替えインターフェース
│  ├─ TitleScene.h / .cpp   # タイトル画面
│  ├─ GameScene.h / .cpp    # メインのバトル画面(パリィ判定・勝敗判定)
│  ├─ Enemy.h / .cpp        # 敵キャラクター(ステートマシン)
│  └─ Player.h / .cpp       # プレイヤーキャラクター(見た目のみ)
└─ data/                    # 画像アセット
   ├─ Title.png              # タイトル画面の背景
   ├─ Background.png         # バトル画面(アリーナ)の背景
   ├─ Clear.png              # クリア画面の背景
   ├─ Player/                # プレイヤーのスプライト(Idle / Protect / Hurt)
   └─ Samurai/                # 敵のスプライト(Idle / Attack_1)
```
